A travel-stay booking platform inspired by #Airbnb.
It is a full-stack travel listing web app where users can explore destinations, create listings, book stays, and manage their own profile.
It focuses on CRUD operations, authentication, session management, and responsive UI.

🚀 Tech Stack

Frontend: HTML, CSS, EJS, Bootstrap, JavaScript.
Backend: Node.js, Express.js
Database: MongoDB (Mongoose ORM)
Authentication: Passport.js
Tools: Git, GitHub, Cloudinary (image upload), Render
